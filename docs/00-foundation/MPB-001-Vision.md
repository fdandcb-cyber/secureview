# MPB-001 — Vision

A trustworthy, education-first security-technology platform. It helps a buyer
understand what to buy, why, how components work together, what can go
wrong, and where to get real local service — before it asks them to buy
anything.

- Initial domain: CCTV and surveillance. Odisha-first, India-scalable.
- Philosophy: educate before selling. Recommendations are evidence-based,
  never forced, never dependent on sponsorship.
- The platform behaves like a knowledgeable consultant, not a storefront.
- Built as a modular web app (not an ERP), architected so it can become a
  licensable SaaS later without a rewrite.

Full detail: see `CCTV_Master_Blueprint_v2.md` (source document for this repo).
